## 2. Mode d'emploi

1. Une planche = un message ChatGPT (génération d'image) = une image. Colle le bloc tel quel, il est complet.
2. Vérifie : 8 objets séparés, **dans l'ordre**, aucun texte ; fond transparent (ou magenta pur uni).
   Fond blanc ou dégradé → « regenerate with a transparent background ».
3. Enregistre sous `art-incoming/missing/sheet-<n>.png`.
4. Découpe : le slicer actuel (`tools/slice_icon_sheet.py`) est en 3×2 ; il lui faut un mode 4×2 `--missing`
   (table d'ids = l'ordre de ce fichier). Demande-le-moi quand les premières planches sont prêtes.

Les **éclats** (`*_shard`, 30 objets, en fin de chaque monde ; « Shard » dans le nom) pourraient aussi se passer d'art :
le jeu peut afficher l'icône de l'arme parente avec un badge « fêlure ». Planches optionnelles.
